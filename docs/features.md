# 実装済み機能一覧

このページは **Markdown WYSIWYG Editor でできること** と **その操作方法** を、機能単位でまとめたものです。
「編集画面で見たままに書けるMarkdownエディタ」として使えます。書いた内容はそのまま通常のMarkdownファイル（`.md`）として保存されます。

> 💡 内部の仕組み（変換の仕組み・モジュール構成・データフロー）を知りたい場合は [アーキテクチャ](./architecture.md) を参照してください。
> ⌨️ キーボードショートカットの一覧は [コマンド・キーバインド一覧](./commands-and-shortcuts.md) にまとまっています。

---

## エディタを開く・切り替える

- `.md` ファイルを開くと、**自動でWYSIWYGエディタ**で開きます。
- WYSIWYGと通常のテキストエディタを **`Ctrl+Shift+M`（Mac: `Cmd+Shift+M`）** で切り替えられます。
- コマンドパレット（`Ctrl+Shift+P`）からも操作できます。
  - **Markdown: WYSIWYGエディタで開く**
  - **Markdown: テキストエディタで開く**
  - **Markdown: エディタ切り替え (WYSIWYG/テキスト)**
  - **Markdown: 新しいWYSIWYGドキュメントを作成**

書いた内容は編集するたびに自動でファイルへ反映されます（保存操作は通常どおり `Ctrl+S`）。改行コード（CRLF/LF）は元のファイルのまま保たれます。

---

## 文字の装飾

入力中に記法を打ち終えた時点で、その場で見た目に反映されます（ライブ変換）。カーソルを装飾の内側に置くと元のMarkdown記法（`**` など）が薄く表示され、記号ごと直接編集できます。カーソルを外すと再び装飾表示に戻ります。

| できること | 記法 | ショートカット |
|---|---|---|
| 太字 | `**太字**` | `Ctrl+B` / `Cmd+B` |
| 斜体 | `*斜体*` | `Ctrl+I` / `Cmd+I` |
| 太字＋斜体 | `***太字斜体***` | — |
| 下線 | `++下線++` | `Ctrl+U` / `Cmd+U` |
| 取り消し線 | `~~取り消し~~` | `Ctrl+Shift+X` / `Cmd+Shift+X` |
| インラインコード | `` `code` `` | — |

- 装飾は入れ子にできます（例: 太字の中に斜体）。
- インラインコード（`` `...` ``）の中に書いた `**` や `[]()` などの記号は装飾に変換されず、そのまま表示されます。

---

## 見出し・段落

- 行頭に `#`〜`######` を付けて `H1`〜`H6` の見出しを作れます。ツールバーの **H1 / H2 / H3** ボタンからも設定できます。
- 見出し記法を書いた行で `Enter` を押すと見出しが確定し、次の段落へ進みます。
- 空行で段落が区切られます。段落内での改行は `Shift+Enter` 相当（`<br>`）になります。

---

## リスト

- **箇条書き**: 行頭で `- ` または `* ` ＋スペース
- **番号付きリスト**: 行頭で `1. ` ＋スペース
- **入れ子**: 行をインデント（スペース2つ、またはタブ）すると1段深いリストになります
- 上記はツールバーの箇条書き / 番号付きボタンからも作れます。

### タスクリスト（チェックボックス）

- `- [ ] やること` / `- [x] 完了` でチェックボックス付きのリストになります。
- 表示されたチェックボックスを**クリック**すると完了/未完了が切り替わり、ファイルにも即座に反映されます。

---

## 引用・アラート（GitHub風の注意ボックス）

- 行頭に `> ` を付けると引用ブロックになります。`> > ` でさらに深い入れ子の引用も作れます。
- 引用の末尾で `Enter` を押すと引用を抜けます。`Shift+Enter` は引用の中で改行します。
- 引用の先頭行を次のマーカーにすると、**色分けされた注意ボックス**になります（GitHub準拠）。

  | マーカー | 用途 |
  |---|---|
  | `> [!NOTE]` | 補足・メモ |
  | `> [!TIP]` | ヒント |
  | `> [!IMPORTANT]` | 重要 |
  | `> [!WARNING]` | 警告 |
  | `> [!CAUTION]` | 注意（危険） |

  マーカーを打ち終えた時点でボックスに変わります。ボックスの中でも `Enter`／`Shift+Enter` は引用と同じ感覚で使えます。

---

## リンク

- `[表示テキスト](URL)` でリンクを作れます。
- **`Ctrl+K`（Mac: `Cmd+K`）** またはツールバーのリンクボタンで、リンクの挿入・編集ダイアログを開けます。
  - テキストを選択してから開くと、その文字がリンクテキストの初期値になります。
  - 既存リンクの中で開くと、そのリンクの編集（リンク解除も可能）になります。
- **クリックの挙動**（編集中の誤操作を防ぐため VS Code 本体と同じ）:
  - 通常クリック → カーソルを合わせるだけ（リンク先へは飛ばない）
  - **`Ctrl`（Mac: `Cmd`）＋クリック** → リンク先を開く（`#見出し` はページ内スクロール、http/https/mailto は外部で開く）

---

## 表（Excel風の編集）

Markdownのパイプ表（`| A | B |`）が、そのまま編集できる表として表示されます。

- 各セルをクリックして直接編集できます。
- セルにカーソルを置くと**ツールバー**が出て、次の操作ができます。
  - ⬆️⬇️ 行を上/下に追加、⬅️➡️ 列を左/右に追加
  - 🗑️ 行/列を削除（最後の1行・1列は残す）
  - 📋 表全体をコピー（タブ区切りで Excel などへ貼り付け可能）
- **キーボード移動**: `↑`/`↓` で同じ列の上下へ、`←`/`→` でセル端から隣のセルへ、`Tab`/`Shift+Tab` で前後のセルへ、`Enter` で次の行へ。
- Excel などからコピーした表（タブ・改行区切り）をセルに貼り付けると、複数セルへ自動で展開されます。
- **表の挿入**: **空行**（または本文が無いエディタの余白）を**右クリック**すると「➕ 表を挿入…」が出ます。行数・列数を入力して OK を押すと、その位置へ空の表が挿入され、すぐ編集できます。本文テキストや既存の表・数式・Mermaid 図の上ではブラウザ既定のメニュー（貼り付けなど）が優先されます。

## 画像のクリップボード貼り付け

スクリーンショットなどの画像をコピーして、エディタに**貼り付け**（`Ctrl+V` / `Cmd+V`）できます。

- 画像は**編集中の Markdown ファイルと同じフォルダ**へ `image-<日時>.<拡張子>`（例: `image-20260720-153012.png`）という名前で保存され、その**相対パス**が `![](…)` としてカーソル位置へ挿入されます。
- 同名ファイルがあると `-1`, `-2` … を付けて別名で保存します（既存ファイルを上書きしません）。
- **Markdown ファイルを保存してから**お使いください（未保存＝ファイルの場所が未確定の場合は、保存を促すメッセージが出て何もしません）。
- Excel やブラウザからのコピーのように**テキストも一緒に含む**クリップボードは、従来どおり表／テキストとして貼り付けます（画像では上書きしません）。
- `![alt](url)` の画像記法はエディタ内で画像（`<img>`）として表示します。**Markdown ファイルからの相対パス**（例: 同じフォルダの `image-20260720.png` や `assets/logo.png`）もエディタ内で実際の画像として表示されます（Markdown ファイルを保存済みの場合。`data:` URI や表示可能な URL も同様に描画されます）。編集中も元の相対パスがそのまま保たれ、保存後の Markdown ファイルは通常のビューアでも同じく画像として表示されます。

## コードブロックとシンタックスハイライト

- ` ```言語名 ` … ` ``` ` でコードブロックを作れます。言語名（`js`, `python`, `go` など）を書くとキーワードなどが色分けされます。
- フェンス行（` ``` ` / ` ```lang `）で `Enter` を押すとその場でコードブロックになり、中にカーソルが入ります。
- コードブロック内の `Enter` は改行のみで、ブロックからは抜けません。
- 約36言語に対応（JavaScript/TypeScript/JSON/YAML/Go/Rust/Python/Bash/PowerShell/C/SQL など）。言語未指定・未対応のときは内容から自動判定します。
- コードブロックの右上に言語名ラベルが表示されます。

---

## Mermaid図

コードブロックの言語を `mermaid` にすると、そのコードが**図として表示**されます。

- 図の右上のボタンで表示を切り替えられます。
  - 👁️ プレビューのみ
  - ⊞ 分割表示（左でソースを編集しながら右でプレビュー）
- 分割表示ではソースをその場で編集でき、少し待つと図が更新されます。構文エラー時はエラー内容が表示され、直前の正常な図は保たれます。
- 図を**右クリック**すると、
  - 📋 画像をコピー（PNGでクリップボードへ）
  - 💾 PNG画像として保存（保存ダイアログ）

  高解像度のPNGとして書き出されます。

---

## 数式（KaTeX）

- **インライン数式**: `$...$`（例: `$E = mc^2$`）
- **ブロック数式**: `$$...$$`（複数行可）
- 閉じの `$` / `$$` を打った時点で数式として描画されます。
- 数式を**クリック**すると元の式が表示され、その場で編集できます。
- ドル記号そのものを書きたいときは `\$100` のようにエスケープします。
- ブロック数式を**右クリック**すると「画像としてコピー」でPNGにできます。メニュー上部で**背景色（透過／白／黒）**と**文字色（自動／黒／白）**を選べます（既定は背景=白・文字=自動）。文字色「自動」は背景に追従（白・透過→黒、黒→白）し、透過背景をダークな資料へ貼るときは文字色に「白」を選べば埋もれません。

## そのほかの要素

- **水平線**: `---` / `***` / `___` だけの行（3文字以上）。その行で `Enter` を押すと水平線になります。
- **目次(TOC)**: **`Ctrl+Shift+O`（Mac: `Cmd+Shift+O`）** またはツールバーの 📑 ボタンで、文書内の見出しから目次を自動生成してカーソル位置に挿入します。目次のリンクを `Ctrl`＋クリックすると該当見出しへスクロールします。

---

## 検索・置換

**`Ctrl+F`（Mac: `Cmd+F`）** で検索ウィジェットが開きます（選択中の文字があれば自動で検索語に入ります）。

- 次/前の一致へ移動: `Enter` / `Shift+Enter`（`F3` なども可）
- 一致件数を `現在/全体` 形式で表示
- オプション: `Aa` 大文字小文字を区別（`Alt+C`）、`ab` 単語単位（`Alt+W`）、`.*` 正規表現（`Alt+R`）
- **置換**: 検索欄の下の置換欄で、現在の一致（「置換」）または全一致（「全置換」）を置き換えられます。
- `Escape` または閉じるボタンで終了します。

---

## 表示の切り替え・補助表示

- **Raw/プレビュー切り替え**: ツールバーの `📄 Raw` / `👁️ Preview`、または **`Ctrl+/`（Mac: `Cmd+/`）** で、Markdownソースの直接編集と見たままの編集を切り替えられます。どちらのモードでも編集内容はファイルへ反映されます。
- **行番号**: RawモードでもWYSIWYGモードでも、左端にMarkdownソースの行番号が表示されます。
- **単語数・文字数**: エディタ右下に現在の単語数・文字数がリアルタイムで表示されます。

---

## 見た目・テーマ

- 配色・フォント・余白はVS Codeのカラーテーマに自動で追従します。ライト/ダークどちらのテーマでも読みやすく表示されます。
- Mermaid図や表なども現在のテーマに合わせて表示されます。

---

## 書式ツールバー

エディタ上部に常に固定表示されるツールバーから、次の操作をボタンで実行できます（本文を下までスクロールしても消えません）。

> 太字 / 斜体 / 下線 / 取り消し線 ｜ H1 / H2 / H3 ｜ 箇条書き / 番号付きリスト / 引用 ｜ リンク / コードブロック ｜ 目次(TOC)

ボタンを押しても本文の選択範囲は失われません。

---

## 現時点の制限事項

- 画像の挿入は未対応です。
- 表のセル結合は未対応です。
- 脚注は未対応です。
- リスト項目内の複数段落（項目の続き行）は未対応です。
- シンタックスハイライトは、対応言語以外は内容からの自動判定になります。
